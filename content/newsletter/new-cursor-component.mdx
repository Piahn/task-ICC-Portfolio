Just added a new component to my lab: `<Cursor>`, a custom animated cursor system built with `motion/react`. It's perfect for interactive demos and playful interactions.

## Features

- **Fluid Spring Physics**: Smooth following with configurable stiffness and damping.
- **Dynamic Content States**: Scales up or changes label depending on what the user is hovering over.
- **Performance Optimized**: GPU-accelerated transforms without layout thrashing.
